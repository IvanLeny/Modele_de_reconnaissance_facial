# Logo de la structure

Déposez ici le logo du MINPMEESA sous le nom **`logo.png`** (ou `logo.jpg`,
`logo.svg`). Il s'affichera automatiquement dans l'en-tête de l'application.

Vous pouvez aussi le téléverser directement depuis l'interface :
onglet **« Mettre à jour la documentation » → « Logo de la structure »**.

En l'absence de logo, un monogramme tricolore (vert/jaune/rouge) est affiché.

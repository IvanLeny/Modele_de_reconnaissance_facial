# Images de l'application

Déposez ici les images de la structure. Elles s'affichent automatiquement dans
l'interface après rechargement de la page. Nommez chaque fichier exactement ainsi
(extension `.png`, `.jpg` ou `.svg`) :

| Nom du fichier      | Où elle apparaît                         | Suggestion                              |
|---------------------|------------------------------------------|-----------------------------------------|
| `logo.png`          | En-tête (petit logo rond)                | Logo MINPMEESA                          |
| `banniere.png`      | Bandeau large sous l'en-tête             | Photo institutionnelle / Journées PME   |
| `couverture.png`    | Barre latérale (« Dernier Annuaire »)    | Couverture de l'Annuaire statistique    |

En l'absence de `logo.png`, un monogramme tricolore (vert/jaune/rouge) est affiché.

## Plus simple : depuis l'interface

Onglet **« Mettre à jour la documentation » → « Images de l'application »** :
téléversez chaque image, sans avoir à manipuler les fichiers.
